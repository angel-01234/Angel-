# ComicCraft - AI Comic Story Creator

A simple college-project web application that uses Google's Gemini API to generate comic story scripts.

## Features

- Enter a comic idea
- Choose a genre
- Choose 4, 6, or 8 panels
- Generate a title and characters
- Generate panel scenes, captions and dialogue
- Responsive interface

## Requirements

- Node.js 18+
- Internet connection
- Gemini API key

## Run the project

1. Extract the ZIP.
2. Open a terminal inside the project folder.
3. Run:

```bash
npm install
npm run dev
```

4. Open the local address shown by Vite.
5. Enter your Gemini API key in the app.
6. Enter a story idea and click **Generate Comic Story**.

## Important

This demo accepts the API key in the browser, which is suitable only for a local college demonstration. For a real deployed application, keep the API key on a secure backend/server and never expose it in frontend code.
